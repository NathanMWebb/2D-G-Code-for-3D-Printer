Tips
  • High contrast or line art images trace cleanest
  • Boost contrast slider before adjusting threshold
  • Use Pre-blur for noisy/pencil sketch images
  • Tape paper flat to the build plate first
  • Start pen-down Z at -0.5mm and adjust from there
  • Drag .gcode directly into Bambu Studio to load
  • Disable filament detection before every run
